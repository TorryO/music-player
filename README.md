# Music Player

A simple, dependency-free web music player built with HTML, CSS, and vanilla JavaScript.

## Features

- Load multiple audio files from your device
- Playlist with click-to-play tracks
- Play / pause, previous / next controls
- Seek bar and volume control
- Keyboard shortcuts: `Space` (play/pause), `←`/`→` (seek 5s)
- Auto-advance to the next track when a song ends

## Usage

Open `index.html` in a browser, then click **+ Add music files** and choose audio files from your computer.

No build step or server required.

## Getting started

```bash
git clone <repo-url>
cd music-player
open index.html   # or just double-click the file
```
